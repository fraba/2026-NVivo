Installing NVivo 15 (University licence)

The University has an enterprise licence for staff and students. The official ICT instructions, including the licence key, are here (UniKey login): How to get a copy of NVivo (ICT knowledge base, KB0011243).

You need: an active UniKey, your University email address (personal email accounts must not be used), and a computer that meets NVivo's system requirements.

  1. Create (or log in to) your myLumivero account at my.lumivero.com/account/licence-registration, using your University email.
  2. Register the University's enterprise licence key in the portal. Copy the key from the ICT article linked above.
  3. Check your email (including spam) for the automated message from Lumivero with the download links and installation instructions.
  4. Download and install NVivo 15.
    • Windows: run the installer and accept the Microsoft SQL Server component. NVivo needs it to work. NCapture (a browser add-on for capturing web pages and social media) is optional.
    • Mac: open the .dmg file and install as usual.
  5. Activate: the first time you open NVivo, sign in with your myLumivero credentials.
  6. Create your user profile (name and initials) when asked. NVivo uses your initials to record who created or changed what in a project.

Good to know

  • Older version installed? Please upgrade to NVivo 15. Opening an existing project in NVivo 15 converts it to the new format automatically. Keep a backup copy first, because a converted project can't be opened in older versions.
  • NVivo Collaboration Cloud is not included in the University licence and must not be purchased individually. Don't use the in-app option to log in to Collaboration Cloud.
  • Windows or Mac? Both work for everything we cover. The Mac version looks a little different, and some menus are in different places.
  • Stuck? Contact the ICT Service Desk, or email us as soon as possible (see Help below). The facilitators will also be in the room 10 minutes early.

Practice data: #SydneyRent

[LINK TO nvivo-practice-data.zip]

We use one small dataset in both sessions: 86 short social media posts by 19 users about housing and renting in NSW (March–May 2026).

  • posts/: one Word file per user. Each file becomes one case in NVivo.
  • users.xlsx: each user's gender, age group, tenure (renter, owner, landlord, living with parents) and location. We import it in Session 2.
  • all_posts.xlsx: all posts in one table.

The research question we'll use: How do people in NSW make sense of the housing crisis: what do they experience, and whom do they blame?

This is synthetic data. All users and posts are fictional and were written for this workshop.

Programme

Both sessions follow Mortelmans (2025), Doing Qualitative Data Analysis with NVivo. Chapter numbers are in brackets.

Session 1: From data to codes (10:00–11:30)

  • What NVivo can and cannot do for you: code and retrieve (Ch. 2–3)
  • Installing and configuring; the workspace (Ch. 4–5)
  • Setting up a project, importing data, backups (Ch. 6)
  • Memos and annotations (Ch. 7)
  • Thematic coding: deductive and inductive, coding stripes, code hierarchies, aggregating (Ch. 8)
  • Hands-on: import the #SydneyRent posts, write memos, build and code with your first codebook

Session 2: From codes to analysis (12:30–14:00)

  • Refining the codebook: merge, split, uncode (Ch. 8)
  • Cases and classifications (Ch. 9)
  • Queries: text search, coding, matrix coding and more (Ch. 12)
  • Exploring and visualising: diagrams, framework matrix, maps (Ch. 10, 13)
  • AI and (semi-)automatic coding (Ch. 19); working in teams (Ch. 20); reporting and exporting (Ch. 14)
  • Hands-on: import the classification sheet, run queries, compare themes across renters, owners and landlords

Only coming to Session 2? Before 12:30, create a new project and Import → Files all the files in posts/, ticking "Create a case for each imported file".

Your own data: a reminder

  • Please don't bring identifiable participant data to the workshop. Use the practice data.
  • An NVivo project is a single file that contains all your data. Store it where your ethics approval and data management plan say (e.g. the Research Data Store), and keep regular backups.
  • Before using NVivo's AI features on your own data, check that your ethics approval covers it, and disclose AI-assisted steps in your thesis.
