# Canvas module: NVivo for HDR researchers

## Suggested module structure

1. **Page: Start here: NVivo workshops (9 Nov)**. Paste `start-here.html` into the page's HTML editor (Rich Content Editor → `</>`). This is the link to email students.
2. **File: nvivo-practice-data.zip**. Upload from `data/nvivo-practice-data.zip`. Copy its Canvas link into the two `[LINK TO nvivo-practice-data.zip]` placeholders on the page.
3. **External URL: How to get a copy of NVivo (ICT KB0011243)**: https://sydneyuni.service-now.com/sm?id=kb_article_view&sysparm_article=KB0011243
4. **External URL: Mortelmans (2025), open-access book**: https://doi.org/10.1007/978-3-031-66014-6
5. **File: Session 1 slides** (rendered HTML or PDF). Publish on the day.
6. **File: Session 2 slides**. Publish on the day.
7. **External URL / Survey: Feedback form**

## Placeholders to fill in `start-here.html`

- `[ROOM / ZOOM LINK]`
- `[LINK TO nvivo-practice-data.zip]` (twice)
- `[CONTACT EMAIL]` (twice)
- `[LINK, available on the day]` (slides, twice)
- `[FEEDBACK FORM LINK]`

The licence key is deliberately **not** copied into Canvas. Students get it from the ICT article (UniKey login).
